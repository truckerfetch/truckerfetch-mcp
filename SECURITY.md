# Security

Report suspected security issues privately to support@truckerfetch.com with the repository, affected version, operation and a minimal synthetic reproduction. Do not include API keys, OAuth tokens, webhook secrets or carrier contact records. Do not open a public issue containing sensitive details.

If a credential is exposed, revoke it in the TruckerFetch dashboard and replace it in your secret manager. Remove it from logs and repository history as appropriate. Keep production keys out of tests and CI.

These repositories expose client integration code and public interface metadata only. MIT licensing does not grant access to customer data or permission to bypass subscription, authorization, privacy or source restrictions.
